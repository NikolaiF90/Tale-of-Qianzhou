## 2026-08-31 — Locations Update

### Changed
- Adjusted `x`/`y` coordinates for all 36 Locations to better align with the realm map image and established lore (river source at Fujin, Guyu Island's position relative to Muyu/Linzhao, and related fixes).
- Updated image for **Tiexue Camp**.

### ⚠️ Action required for existing saves
This update **does not sync automatically** to saves already in progress. If you're currently playing, you'll need to manually update your save's `locations` section via the in-game State Editor.

**[→ Full instructions: patch-locations-update.md](docs/patch-locations-update.md)**
**[→ Download the updated locations JSON](docs/locations_section.json)**

If you haven't started a save yet, no action needed — new saves already use the corrected data.
